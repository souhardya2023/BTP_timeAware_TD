# presentation - the final talk, its figures, tables and scripts

Title: **Characterising AI-Induced Technical Debt and Its Impact on Software Maintenance** (B.Tech project 2026-27, IIT Kharagpur).
The talk is about 14 minutes. Its main goal is the prioritisation of technical debt and the evaluation of that prioritisation.

## Code (everything in the final deck that is a graph, table or diagram is made by Python)

| file | what it makes | output |
|---|---|---|
| `make_figures.py` | the 8 plots, with matplotlib defaults: pairs funnel, pairs per type and language, fix time per type, accuracy by protocol, seven classifiers, capture bars, capture curve, AUC | `figs/*.png` |

| `build_deck_final.js` | places the images, text and logo on the slides with pptxgenjs and writes the deck and `tables_spec.json` | `TD_prioritisation_presentation_f2.pptx` |
| `build_all.sh` | runs everything in the right order (figures, architecture, table specs, table images, deck) | |

| `build_deck.js` | the first generator (native PowerPoint charts and tables). Kept as a record | |
| `prioritization_eval.py` | the ranking evaluation: capture@k, lift, NDCG, Spearman, bootstrap intervals, baselines | `data/prioritization_*.csv`, `data/prio.json` |
| `capture_curve.py` | capture at every k (5 to 100) and the paired difference hurdle minus persistence | `data/capture_curve.csv`, `data/curve.json`, `data/hurdle_vs_persistence.json` |

`data/` holds the numbers behind Results 2 to 4. They are computed from `../interest_exp/results/pm_predictions.csv` (models `zero`, `persistence`, `rf_pm`, `hurdle_rf`; protocols `leave-one-repo-out` and `temporal`).
The numbers of Result 1 come from `../ml_model/results/summary.csv`.

## How to rebuild the deck

Needs Python 3 with matplotlib, numpy and pandas; Node.js with `pptxgenjs` (`npm install pptxgenjs`; if it is installed outside this folder, set `NODE_PATH` to its `node_modules`).

```
cd final_folder/presentation
python3 prioritization_eval.py        # only if pm_predictions.csv changed
python3 capture_curve.py              # only if pm_predictions.csv changed
./build_all.sh                        # figures, tables, deck -> TD_prioritisation_presentation_f2.pptx
```
To change the text of a table, edit its rows in `build_deck_final.js` and run `./build_all.sh` again. The final deck `TD-presentation.pptx` was edited by hand in a slide editor, so rebuilding does not overwrite it; copy figures or tables from `figs/` and `tables/` if you want to update it.

## Things to know before presenting

* The fix times come from the ground-truth time model (`../pipeline/bug_injection/sample_times.py`), not from measurements with developers. The time-feature gain is conditional on that model (controls: `../results/04_time_feature.md`). The script says so; keep to that wording.
* The headline ranking result ties the persistence baseline (38.5 % against 38.8 % in the top 20 %). The +5.6 points at 50 % budget is marginal.
* The motivation figures (Stanford AI Index, Veracode, IBM, GitClear, CISQ, the Amazon and Replit cases) are from secondary sources and have not been re-checked against the originals. The citation of Wiriyakul and Senivongse (reference [12]) is incomplete.
